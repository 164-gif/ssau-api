# API-кандидаты личного кабинета студента

**Система:** [lk.ssau.ru](https://lk.ssau.ru)  
**Статус:** вход проверен 2026-10-27; карта клиентских маршрутов извлечена из JS главной страницы; один безопасный GET API проверен.

## Вход

`POST /account/login` принимает форму `multipart/form-data`. Перед отправкой клиент загружает страницу входа и переносит скрытые поля формы. В этой проверке вход прошёл, сервер выдал авторизационную сессию; значения cookies и учётные данные не сохранялись.

## Проверенный запрос API

```http
GET https://lk.ssau.ru/api/proxy/dictionaries?slug=timetable_lesson_times
Accept: application/json
Cookie: <авторизованная сессия>
```

Ответ — `200 application/json`, объект с ключами `forHigherEducation` и `forSpo`. Значения словаря не записывались. Это безопасная справочная точка, проверенная после входа.

## Карта маршрутов из клиентских файлов

Главная авторизованного ЛК загрузила 33 JavaScript-файла общим размером около 3,1 МБ. В них найдено 275 различных строк-путей с `/api/`; у 271 пути HTTP-метод сопоставился с ближайшим вызовом клиента. По найденным вызовам: 178 GET, 48 POST, 20 PUT, 24 PATCH и 23 DELETE; метод ещё четырёх путей не удалось определить по локальному контексту.

Список находится в [`data/lk-client-routes.json`](../../data/lk-client-routes.json). Это декларации клиентского кода, а не подтверждение успешного ответа каждого маршрута. Среди модулей есть расписание, посещаемость, текущая успеваемость, заявления, библиотека, публикации, чаты, воинский учёт, кабинеты подразделений и работодателей. Часть функций может требовать другой роли или разрешения.

Изменяющие POST/PUT/PATCH/DELETE-запросы не отправлялись. Персональные ответы API не сохранялись. Маршруты, которые загружены только на страницах или в ролях, не представленных в JS главной, могут отсутствовать в этой выгрузке.
