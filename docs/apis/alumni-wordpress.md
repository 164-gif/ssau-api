# REST API сайта выпускников

**Система:** [alumni.ssau.ru](https://alumni.ssau.ru)  
**Статус:** публичный индекс маршрутов и чтение списка записей проверены 2026-10-27.

## Индекс маршрутов

```http
GET https://alumni.ssau.ru/wp-json/
Accept: application/json
```

Проверенный ответ — JSON-индекс WordPress REST API с 185 шаблонами маршрутов в восьми пространствах имён: `wp/v2`, `oembed/1.0`, `contact-form-7/v1`, `mec/v1`, `yoast/v1`, `mc4wp/v1`, `wp-site-health/v1` и `wp-block-editor/v1`.

Сокращённый снимок структуры сохранён в [`data/alumni-wp-rest-routes.json`](../../data/alumni-wp-rest-routes.json). В нём оставлены шаблоны маршрутов, методы и имена аргументов; содержимое публикаций и описания не копируются. Наличие маршрута в индексе не означает, что анонимному пользователю разрешён каждый метод: WordPress проверяет доступ отдельно для каждой операции.

## Публичные записи

```http
GET https://alumni.ssau.ru/wp-json/wp/v2/posts?per_page=1&_fields=id,date,slug,link,title
```

Без авторизации проверен ответ `200 application/json` с одной записью. Для проверки запрошены только поля `id`, `date`, `slug`, `link`, `title`; тело публикации и значения полей не сохранены.

Полезные параметры WordPress API:

| Параметр | Значение |
| --- | --- |
| `per_page` | Число результатов; используется для ограниченной выборки |
| `_fields` | Разрешённый список полей, чтобы уменьшить ответ |
| `page` | Номер страницы |
| `search` | Поиск |
| `after`, `before` | Ограничение по дате |

Параметры списка видны в живом индексе маршрутов. Проверен только безопасный GET с `per_page=1` и `_fields`; пагинация, поиск и фильтры отдельно не проверялись.

## Методы изменения

Индекс объявляет также POST, PUT, PATCH и DELETE на части маршрутов. Эти операции в проекте не отправлялись и в OpenAPI как разрешённые действия не описываются. Для каталога используются только GET-запросы.
