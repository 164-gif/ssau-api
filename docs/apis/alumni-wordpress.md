# REST API сайта выпускников

**Система:** [alumni.ssau.ru](https://alumni.ssau.ru)  
**Статус:** публичный индекс маршрутов и чтение списка записей проверены 2026-10-27.

## Индекс маршрутов

```http
GET https://alumni.ssau.ru/wp-json/
Accept: application/json
```

Проверенный ответ — JSON-индекс WordPress REST API с 185 шаблонами маршрутов в восьми пространствах имён: `wp/v2`, `oembed/1.0`, `contact-form-7/v1`, `mec/v1`, `yoast/v1`, `mc4wp/v1`, `wp-site-health/v1` и `wp-block-editor/v1`.

Сокращённый снимок структуры сохранён в [`data/alumni-wp-rest-routes.json`](../../data/alumni-wp-rest-routes.json). В нём оставлены шаблоны маршрутов, методы и имена аргументов; содержимое публикаций и описания не копируются. Наличие маршрута в индексе не означает, что анонимному пользователю разрешён каждый метод: WordPress проверяет доступ отдельно для каждой операции.

## Публичные записи

```http
GET https://alumni.ssau.ru/wp-json/wp/v2/posts?per_page=1&_fields=id,date,slug,link,title
```

Без авторизации проверен ответ `200 application/json` с одной записью. Для проверки запрошены только поля `id`, `date`, `slug`, `link`, `title`; тело публикации и значения полей не сохранены.

Полезные параметры WordPress API:

| Параметр | Значение |
| --- | --- |
| `per_page` | Число результатов; используется для ограниченной выборки |
| `_fields` | Разрешённый список полей, чтобы уменьшить ответ |
| `page` | Номер страницы |
| `search` | Поиск |
| `after`, `before` | Ограничение по дате |

Параметры списка видны в живом индексе маршрутов. Проверен только безопасный GET с `per_page=1` и `_fields`; пагинация, поиск и фильтры отдельно не проверялись.

## Другие проверенные публичные GET-маршруты

Для коллекций использовались `per_page=1` и `_fields` с коротким списком полей. В репозиторий записаны только статус, форма ответа и названия полей — не значения публикаций или медиа.

| Маршрут | Результат проверки |
| --- | --- |
| `/wp-json/wp/v2/pages` | `200`, одна запись в ограниченной выборке |
| `/wp-json/wp/v2/mec-events` | `200`, одна запись в ограниченной выборке |
| `/wp-json/wp/v2/categories` | `200`, одна категория |
| `/wp-json/wp/v2/media` | `200`, один элемент; проверены только `id`, `slug`, `media_type`, `mime_type` и служебные поля |
| `/wp-json/wp/v2/news` | `200`, пустой массив в проверенном запросе |
| `/wp-json/wp/v2/avada_faq` | `200`, пустой массив в проверенном запросе |
| `/wp-json/wp/v2/avada_portfolio` | `200`, пустой массив в проверенном запросе |
| `/wp-json/wp/v2/tags` | `200`, пустой массив в проверенном запросе |
| `/wp-json/mec/v1/events` | `200`, пустой массив в проверенном запросе |
| `/wp-json/wp/v2/types` | `200`, 15 зарегистрированных типов записей |
| `/wp-json/wp/v2/taxonomies` | `200`, 10 зарегистрированных таксономий |

Пустой массив означает только, что выбранная коллекция вернула пустой результат при этой проверке; это не доказывает, что маршрут всегда пуст. `/wp/v2/users`, `/wp/v2/comments` и пользовательские каталоги присутствуют в индексе, но не запрашивались из-за риска получить персональные данные.

## Методы изменения

Индекс объявляет также POST, PUT, PATCH и DELETE на части маршрутов. Эти операции в проекте не отправлялись. OpenAPI описывает только выбранные подтверждённые GET-точки; полный снимок методов находится в JSON-индексе. Для каталога используются только GET-запросы.
