# Публичный API новостей

**Система:** официальный портал Самарского университета (`ssau.ru`)  
**Статус:** официально документировано; GET-маршрут и JSON-ответы проверены 2026-10-27  
**Источник:** [руководство Самарского университета по API](https://ssau.ru/api_docs)

## Маршрут

```http
GET https://ssau.ru/api/news/
Accept: application/json
```

Документация также приводит адрес без завершающего `/` и примеры по HTTP. HTTPS-адрес проверен и отвечает `200 application/json`. API предназначен для чтения новостей портала.

## Параметры

| Параметр | Тип | Значение по умолчанию | Описание |
| --- | --- | --- | --- |
| `id` | integer | — | Одна запись по идентификатору |
| `q` | string | — | Поиск по названию без учёта регистра |
| `limit` | integer | `10` | Максимум записей; верхняя граница `50` |
| `index` | integer | `0` | Смещение начала выборки |
| `date-start` | `YYYY-MM-DD` | — | Нижняя граница даты публикации |
| `date-end` | `YYYY-MM-DD` | — | Верхняя граница даты публикации |
| `type` | enum | `all` | `all`, `news`, `announcements`, `sitenews` |
| `tags` | string | — | Один или несколько тегов через запятую; пробелы в теге заменяются на `_` |
| `lang` | enum | `ru` | Язык: `ru` или `en` |
| `slideshow` | boolean | `false` | Только записи, включённые в слайдшоу главной страницы |
| `xml` | boolean | `false` | При `true` возвращает XML вместо JSON |

Официальная документация описывает `index` как индекс первого результата и указывает пример смещения на 11 для второй десятки. Фактическая семантика смещения отдельно не проверялась на границах страниц — считайте это неподтверждённой деталью.

## Примеры

```bash
# Последние 10 новостей
curl 'https://ssau.ru/api/news/?limit=10&index=0&lang=ru'

# Получить запись по ID
curl 'https://ssau.ru/api/news/?id=26231'

# Фильтрация по типу и датам
curl 'https://ssau.ru/api/news/?type=announcements&date-start=2026-01-01&date-end=2026-12-31&limit=20'

# XML
curl 'https://ssau.ru/api/news/?type=news&xml=true'
```

## Ответ

Для JSON возвращается массив записей. В официальном примере перечислены поля:

| Поле | Описание |
| --- | --- |
| `id` | Идентификатор |
| `title` | Заголовок |
| `descr` | Краткое описание |
| `pubText` | Текст публикации, HTML |
| `pubDate` | Дата и время публикации (`YYYY-MM-DD hh:mm:ss`) |
| `pic` | Изображение или миниатюра |
| `type` | Тип публикации |
| `slideshow` / `slidewhow` | Флаг слайдшоу; в актуальном наблюдавшемся ответе поле называлось `slidewhow`, а в документации — `slideshow` |
| `slide` | Путь к материалу слайдшоу |
| `tags` | Теги через запятую |
| `url` | Ссылка на публикацию |

Название поля слайдшоу расходится между документацией и живым ответом. Клиентам следует терпимо обрабатывать оба варианта.

## Наблюдения при проверке

- `GET /api/news/?limit=3&index=0&lang=ru` ответил `200 application/json` и вернул три записи.
- `GET /api/news/?id=26231` ответил `200 application/json`; массив содержал одну запись с `id=26231`.
- API Anything успешно обучил чтение по ID и поиск по `q`; holdout-запрос и повтор без cookies прошли. Инструмент при этом пометил операцию как требующую входа, что противоречит независимому запросу без авторизации; это классификация инструмента, а не подтверждённое требование API. Пока операции не опубликованы в его общем каталоге.
- На `https://ssau.ru/rasp` браузерная загрузка страницы завершилась без обнаружения запроса к API расписания среди кандидатов. Страница указывает, что персонализированное расписание доступно в личном кабинете. Это не доказывает отсутствие внутренних API расписания.

## История и надёжность

Страница документации содержит примеры и данные старых лет, поэтому актуальность каждого параметра нужно проверять отдельно. Текущие запросы подтверждают существование и формат базового GET API, но не являются исчерпывающим тестом всех фильтров, лимитов и XML-ответа.
