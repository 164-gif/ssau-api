# AJAX-фрагменты сайта приёмной кампании

**Система:** `priem.ssau.ru` перенаправляет на `priemsamara.ru`  
**Статус:** маршруты обнаружены в публичном интерфейсе и проверены GET-запросами 2026-10-27
**Доступ:** публичный, вход не нужен
**Формат:** HTML-фрагменты и HTML-таблицы, не JSON

Сайт загружает страницу целиком, а подробности программ и факультетов подставляет в окно через jQuery AJAX. В коде интерфейса это запросы GET.

## Подтверждённые маршруты

| Метод и путь | Назначение | Проверка |
| --- | --- | --- |
| `GET /get_program/{id}` | HTML-карточка образовательной программы | В интерфейсе есть ссылки с числовыми ID; `/get_program/2` вернул `200 text/html` |
| `GET /get_fac/{facultyId}/bac` | HTML-список программ факультета для бакалавриата | `/get_fac/1/bac` вернул `200 text/html` |
| `GET /get_fac/{facultyId}/mag` | HTML-список программ факультета для магистратуры | Ссылка найдена на `/mag`; `/get_fac/1/mag` вернул `200 text/html` |
| `GET /get_asp_fac/{facultyId}` | HTML-список программ факультета для аспирантуры | Ссылка найдена на `/asp`; `/get_asp_fac/1` вернул `200 text/html` |
| `GET /ratings/?pk={programId}&filter={filter}[&pay={pay}]` | HTML-таблица рейтинга абитуриентов | Ссылки найдены на `/programs/`; запрос по ссылке вернул `200 text/html` |
| `GET /ratings_spo/?pk={programId}&filter={filter}[&pay={pay}]` | HTML-таблица рейтинга СПО | Ссылки найдены на `/programs_spo/`; запрос по ссылке вернул `200 text/html` |

Маршрут карточки переиспользуется для разных уровней: `/get_program/1002` найден на странице магистратуры, а `/get_program/10502` — на странице СПО; оба ответа `200 text/html`. Идентификаторы в URL — примеры со страниц, диапазоны ID и правила их выдачи не исследовались.

### Рейтинги зачисления

Списки `/programs/` и `/programs_spo/` содержат ссылки на динамические таблицы рейтингов. В просмотренных ссылках были параметры `pk` (ID программы), `filter` и необязательный `pay`; наблюдались значения `filter=enrolled` для обычного конкурса и `filter=all` для СПО, а также `pay=budget`. Другие допустимые значения фильтров не установлены.

Проверенные ответы содержали заголовки таблиц с конкурсными баллами и данными заявлений. Таблица СПО включает колонку `СНИЛС`. Содержимое строк не сохранялось и не приводится в этом каталоге; рейтинги могут содержать персональные данные, поэтому не выгружайте и не публикуйте списки абитуриентов без необходимости и разрешённого основания.

Браузер добавляет параметр `_` с временной меткой для обхода кэша. Он не выглядит параметром предметной области и в каталог не включён.

## Ограничения ответа

Ответы — большие HTML-фрагменты для отрисовки модального окна, не стабильные JSON-схемы. Карточка программы может содержать информацию о стоимости, местах, учебном плане и контактных лицах. Сырые ответы и персональные контактные поля в репозитории не сохраняются. API Anything-операции для этих маршрутов пока не экспортированы, чтобы не публиковать необработанные карточки с контактной информацией.

## Примеры вызова

```bash
curl -H 'Accept: text/html' 'https://priemsamara.ru/get_program/2'
curl -H 'Accept: text/html' 'https://priemsamara.ru/get_fac/1/bac'
```

ID в примерах факультетов подтверждены соответствующими страницами приёмной кампании. Для маршрута `/get_fac/{facultyId}/{level}` проверены только `bac` и `mag`; аспирантура использует отдельный путь. Список всех факультетов и допустимых уровней не установлен.
