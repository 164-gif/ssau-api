# REST API OJS на сайте журналов

**Система:** [journals.ssau.ru](https://journals.ssau.ru)  
**Статус:** защищённые REST-маршруты обнаружены; без авторизации возвращают `401`.

OJS REST API доступен в контекстном и журнальном путях. Проверены безопасные GET-запросы без токена:

| Метод и путь | Ответ без авторизации |
| --- | --- |
| `GET /index/api/v1/contexts` | `401 application/json` |
| `GET /index/api/v1/contexts/1` | `401 application/json` |
| `GET /index/api/v1/submissions` | `401 application/json` |
| `GET /computeroptics/api/v1/contexts` | `401 application/json` |
| `GET /computeroptics/api/v1/submissions` | `401 application/json` |

Ответ содержит сообщение, что доступа к ресурсу нет. Следовательно, это не публичные операции чтения; успешную схему авторизации и ответы здесь не исследовали. API ключи и учётные данные не использовались.

Способ авторизации этого экземпляра не подтверждён. Дальнейшую проверку можно делать только с разрешённым тестовым аккаунтом или ключом администратора. Не передавайте секреты в URL или каталог.
