# API-кандидаты личного кабинета

**Система:** [cabinet.ssau.ru](https://cabinet.ssau.ru)  
**Статус:** анализ публичного клиентского JavaScript; авторизованные операции не выполнялись.

## Что найдено

Корень сайта перенаправляет на `/login`. Из публичного файла `app-legacy.8b3e44fe.js` извлечено 293 кандидата HTTP-маршрутов: 179 GET, 34 POST, 13 PUT, 38 PATCH и 29 DELETE. В файле [`data/cabinet-client-routes.json`](../../data/cabinet-client-routes.json) записаны только метод и путь с условными именами параметров.

Кандидаты сгруппированы по модулям фронтенда: расписание (`timetable`), индивидуальные учебные планы (`individual-plan`), ИОТ/элективы (`iet`), мониторинг, нагрузка преподавателей, публикации, конкурсы, чаты и инструменты работодателей. Наличие литерала в JS — свидетельство, что клиент его вызывает, но не live-подтверждение успешного ответа сервера. У некоторых путей остаются неоднозначные динамические сегменты; в выгрузке они помечены выражениями из JS.

Клиент настраивает Axios с `withCredentials=true`; базовый путь условно выбирается как `/api` или `/`. Без учётных данных проверены только три безопасных GET-запроса:

| Путь | Ответ |
| --- | --- |
| `/api/timetable/directories/groups` | `401` |
| `/api/timetable/directories` | `401` |
| `/api/monitoring/student-contingent/filter/groups` | `401` |

Это подтверждает защиту этих пробных запросов, но не устанавливает точную схему авторизации для всех маршрутов. Ответы и данные пользователей не сохранялись.

## Ограничения и дальнейшая проверка

Защищённые GET и изменяющие POST/PUT/PATCH/DELETE здесь не вызываются. Для проверки успешных ответов потребуется разрешённый тестовый аккаунт и отдельный выбор безопасных операций. Особого ограничения требуют маршруты `monitoring`, `chats`, `individual-plan` и кадровые модули: они могут обрабатывать персональные или внутренние данные.

`robots.txt` запрещает `/timetable/printing-form/`; этот путь не запрашивался.
